# 前处理、预计算与案例回归的复用结构

当前代码把物理定义、数值移植和验收状态分开。一个案例的引用、单位、载荷、边界、QOI、容差必须先明确；原生适配不支持的模型在求解入口拒绝。现有原生支持仅为单步线弹性CPS8均布体力梁和CAX8外压空心球，不声称能检查任意INP或任意齿轮。

```text
case contract + source reference
   -> predict(case): independent analytical scales
   -> generate(case, mesh_level): native model
   -> preflight(native_readback, case, mesh_level)
   -> locked runtime + isolated solver directory
   -> final-step/process checks + exact raw-field coverage
   -> same-definition QOI + mesh trend + issue ledger
```

## 可以复用的检查

1. **语义先行。** 所有量绑定单位、分量、区域、状态和来源类型；“参考应力”不能混用节点外推应力与原生接触压力。Hertz球的source 7%只属于特定SIYY字段，不转成新求解器的压力容差。
2. **手算量级。** 梁同时计算总力、力矩、截面惯性、EB位移与Timoshenko辅助；空心球用球弹性精确解；Hertz以等效曲率/模量、压合、载荷积分两条算式核对。理论的适用边界独立于数值相近程度。
3. **重读写出的原生模型。** 校验材料、section、单元类型、节点/集合/引用、支承自由度、输出集合和步骤顺序；Q8在3×3高斯点检查Jacobian。该采样不等于全域几何有效性的证明。
4. **载荷既查整体也查分布。** 全局合力/矩不能识别自平衡错误载荷，故另核逐节点/DOF的一致载荷映射。映射复用生成定义，用于发现串改；整体理论积分是独立检查。轴对称子午面积分用于方向/离散几何检查，不叫三维物理合矩。
5. **运行身份。** 锁定实际执行文件而非任意旁路文件的哈希；输入写出后重读；失败、不完整STA和重复末态字段拒绝。运行目录不可复用覆盖。
6. **结果先查资格。** U和支撑RF要求精确节点集合、唯一末态块、有限值。该覆盖不代表S应力场已验证。位移误差、网格变化、物理平衡和工程认可分开，缺项为UNKNOWN。
7. **把失败保留为资产。** 本轮厚度错误不能因薄层结果通过而消失；2×8粗网格拒绝不能从库里删掉。后续改进必须同时复现正确例与已知反例。

## 接入齿轮主线的顺序

先继续使用已有M37低阶拉伸、平面接触与Hertz线接触原生资料；再进入L2齿根与L3齿轮接触。每一级只在同定义QOI闭合后提升资格。M33硬度换算、原表输入和材料极限口径不能用FE收敛代替。

新profile必须提交：完整物理输入、公开/独立参考、期望失败变异、源生模型读回、三维或轴对称区域检查、力与功口径、原始输出覆盖规则和预先确定的网格研究。已有case contract与solver adapter保持分离，避免每加一个案例就修改全局求解流程。

## 尚未闭环的部分与下一步门

- RF：先以当前CCX版本的明确字段/扇区约定和独立静力平衡fixture锁定，再提升为硬门；不要由输出比值拟合一个180系数就宣称轴对称全周力正确。
- 应力与能量：预定义积分点/截面及外功量，要求原始字段完整，排除夹持奇异峰；目前不在新例已验证范围内。
- Cook US3：先查用户单元与section常数语义，不能静默替换为CPS单元。
- 模态：补质量单位、刚体模态、频率排序/近重根及质量归一化检查，再接通频域runner。
- Hertz球：补原MED网格及相应求解器版本，对接触区域、初始间隙/穿透、法向和接触QOI做语义核对；a/R=0.2继续保留有限体影响。

这些是后续明确入口，不因案例数增加而默认完成。
