# 计算问题案例库 v0.1 — 独立审查包

本包登记 **25 个物理案例**：已有 M33/M37 20 个，新增公开来源5个。新增公开案例中，COMET 梁与空心球已无头运行 CalculiX，共10个真实作业；Hertz球接触完成解析核对，Cook US3与模态梁保留来源契约但尚未接通求解。网格、厚度、罚刚度和相位变体不增加物理案例数。

本包用于独立审查输入、实现与证据，不是全部案例工程验收证明。M33、M37 L2/L3保留未验收状态。新公开案例的位移对拍可单独判断；RF物理平衡口径与应力场尚未完整验证，所以整体工程认可仍为false。

## 开始复核

需要 Python 3.10或更新版本，只有标准库，无需联网、安装依赖或启动求解器。已实测Windows CPython 3.12；Linux原生重放未实测。

```powershell
python -B tools/replay.py --output ../case-library-audit
```

命令依次执行：包内文件精确清单与SHA256、12项负向/正向回归、来源契约及Hertz解析重算、全部10个新作业的原生预检与DAT重提取、旧案例全部已归档作业的哈希/覆盖检查。输出目录必须在包外，保持冻结证据不变。退出0表示复核工具和预期结果一致，包括能够重现已知失败，**不表示25例全部通过工程验收**。

## 包内入口

- `CATALOG.json`：25个物理案例索引、证据层级与未完成状态。
- `cases/`：2个可发算公开模型、3个诊断变体、3个待接通公开模型契约。
- `caselab/`：契约、解析预计算、受限原生生成/重读、预检、无头运行和原始字段提取。
- `results/`：10次新作业的INP/DAT/FRD/STA/LOG与不可改写的运行记录；另有粗网格拒绝记录。
- `legacy/`：旧案例规范化定义、去重原始工件、逐作业索引和恢复作业目录工具；详见其README。
- `research/`：5个公开来源、URL/提交/源文件哈希、参考值与许可边界。第三方完整网页/程序缓存未分发。
- `docs/ISSUES.md`：真实失败、修复、尚未闭环问题。
- `docs/ARCHITECTURE.md`：如何在以后计算前复用这些检查。
- `docs/REVIEW-CLOSEOUT.md`：审查发现、修复测试、证据边界。
- `evidence/`：本轮生成的可重放结果摘要，不代替原始文件。

## 再次发算（可选）

本包的离线复核不需求解器。重新FE计算需要合法可用的CalculiX；当前自动runner支持Windows+WSL。复制`runtime.example.json`并填写实际可执行文件、依赖库路径和对应SHA256后：

```powershell
python -B tools/solve_public.py --case cases/public/comet-sphere.json --runtime runtime.mine.json --output ../sphere-new-run
python -B tools/solve_public.py --case cases/diagnostic/beam-t0.01.json --runtime runtime.mine.json --output ../beam-new-run
```

runner校验实际执行路径与哈希、原生输入、退出码、STA最终步、DAT末态节点覆盖；每次必须创建新目录。包未捆绑商业KISSsoft、WSL、CalculiX可执行文件或系统库。旧作业的绝对路径仅为历史来源记录，重放不访问这些路径；M33的.Z12仍需相应KISSsoft授权才能重新打开/计算。
