# FEA 理论基准、适用域与异常诊断审阅

日期：2026-10-29。审阅范围：新建 `fea-readiness` 的理论与判定契约；不执行商业求解器，不更改 M33 或旧核心。外部验收依据为用户提出的初始状态、接触区域、边界条件、前处理语义和三维辅助核查要求。本文件给出可实施规则，不能代替实际 FE 输入与结果的验证。

## 1. 状态与证据契约

每个理论比较至少记录：物理量名称、单位、坐标/投影方向、取值位置或区域、统计方式、参考态、载荷步、输入来源、公式版本、适用域证据、比较对象、容差配置。`contact_pressure_peak`、`integration_point_von_mises_peak`、`root_bending_stress` 是不同量，不可互换。

分别输出 `computed`（算术完成）、`eligible`（该理论适用域有证据）、`needs_evidence`、`not_applicable`；不因公式有数值就宣布 FE 正确。缺失、NaN、未执行、空检查集合均不能变成通过。报告生成成功、求解器返回码为零、非线性收敛、物理模型正确是四个独立状态。

**没有统一 FE/理论误差门。** 项目 profile 必须按命名量配置绝对/相对容差、最小参考量、适用域限制及依据。参考值接近零时不能只除以参考值。示例数值只作为可重算的算术锚点，不是所有齿轮的验收范围。

初始状态是理论适用性的一部分：明确间隙/穿透、预载、刚体定位、接触对身份、实际接触斑、摩擦与载荷路径、约束自由度、材料及几何非线性。带预载或初始闭合运动的 FE 状态不能直接与从零载起算的线弹性理论比较。三维图可检查接触面朝向、背面误选、约束覆盖、接触斑距边缘和穿透；图像本身不能证明载荷单位、材料值或自由体平衡。

## 2. Hertz 线接触

采用 N、mm、MPa。`q` 为该接触对的法向力/有效接触线长度，单位 N/mm，不是总力。曲率使用接触法截面内的有符号相对曲率，外接凸面取正；平面曲率为零。

```text
1/E* = (1-nu1^2)/E1 + (1-nu2^2)/E2
1/R* = 1/rho1 + 1/rho2
a = sqrt(4*q*R*/(pi*E*))             # 接触半宽，mm
p0 = 2*q/(pi*a) = sqrt(q*E*/(pi*R*)) # 最大法向压力，MPa
p(x) = p0*sqrt(1-(x/a)^2), |x|<=a
integral[-a,a] p(x) dx = pi*a*p0/2 = q
```

输入要求：有限 `q>0`、`E1,E2>0`、稳定各向同性材料 `-1<nu<0.5`、有限正相对曲率。`q=0` 使用显式零载分支（a=p0=0），不能执行 0/0。零或负相对曲率不是可套用此线接触公式的有效半径；近平面/共形接触应切换模型。不能用绝对值修复曲率符号。

适用证据：局部光滑、非共形、近似平行线接触，均匀各向同性线弹性体，接触斑较曲率半径、实体厚度、距自由边界和相邻接触斑的距离足够小，摩擦对所比较法向解的影响可忽略。小量比值阈值由 profile 给出并注明依据。有限齿宽端部、倒角/修缘、齿顶边缘接触、明显塑性、大变形、点接触/椭圆接触、多斑或强摩擦都需单独论证。

**p0 大于单轴屈服强度不等于已证明塑性。** 弹性资格需依据接触应力状态、材料准则与适当安全系数；未提供材料弹性限时不得认证弹性有效。相反，单看较低 p0 也不能排除齿根或局部边缘塑性。

验证接触压力时至少同时核查压力形状、接触支撑区、积分力及峰值，说明积分点/节点外推、平滑方法和采样密度。只在 `p>0.15*pmax` 的点拟合 p² 抛物线，即使拟合成功，也不能排除遗漏的小接触斑、尾部和端部载荷。

### 2.1 无量纲与变形关系负例

## 3. 外啮合直齿几何与局部曲率

对标准参数的外啮合渐开线直齿，m 为横向模数、alpha 为横向参考压力角，角度计算使用弧度：

```text
r_i=m*z_i/2; rb_i=r_i*cos(alpha)
ra_i=r_i+(haP+x_i)*m                 # 仅该齿顶定义成立时
inv(alpha)=tan(alpha)-alpha
inv(alpha_w)=inv(alpha)+2*(x1+x2)*tan(alpha)/(z1+z2)
aw=(r1+r2)*cos(alpha)/cos(alpha_w)    # 无侧隙匹配中心距
rw1=aw*z1/(z1+z2); rw2=aw-rw1
pb=pi*m*cos(alpha)
g=sqrt(ra1^2-rb1^2)+sqrt(ra2^2-rb2^2)-aw*sin(alpha_w)
eps_alpha=g/pb
```

上述变位关系隐含相应齿厚与无侧隙条件。若给定实际中心距，应先用 `alpha_w=acos((rb1+rb2)/aw)` 并检查几何定义和 acos 域，不可无条件再用无侧隙关系覆盖它。根号域有效并不代表不存在根切、齿顶干涉或有效渐开线起点限制。内齿、斜齿、交错轴及任意削顶需各自模型。

令 s 沿作用线从节点向主动轮齿顶侧增加：

```text
sA=rw2*sin(alpha_w)-sqrt(ra2^2-rb2^2)
sE=sqrt(ra1^2-rb1^2)-rw1*sin(alpha_w)
rho1(s)=rw1*sin(alpha_w)+s
rho2(s)=rw2*sin(alpha_w)-s
```

需 `sA<=s<=sE` 且两局部曲率正，外齿齿面位置/法线实际对应。节点 s=0 的半径不能代表整个接触周期。双齿对接触时各对使用自己的 q 与曲率，不能每对都分配全载 Fn。

```text
Ft_reference=T/r; Ft_working=T/rw; Fn=T/rb
```

这些式子限准静态、理想直齿法向传力的对应力学定义；不可把 Ft_reference 与工作压力角混用。含摩擦、轴向载荷及三维斜齿力分解需完整向量定义。

斜齿输入需显式区分法向和横向：`mt=mn/cos(beta)`、`tan(alpha_t)=tan(alpha_n)/cos(beta)`、`db=z*mt*cos(alpha_t)`、横向 `pbt=pi*mt*cos(alpha_t)`。alpha_n=20°、beta=28.955° 给出 alpha_t=22.585644183362557°；将 alpha_n 直接用作 alpha_t 的样例应失败。用横向线接触计算斜齿只能命名为相应截面的筛查，不能宣称完整三维 Hertz 曲率或端部压力验证。

齿/接触面身份映射需处理周期角度的 unwrap 和对应关系；跨 0/2pi 的角度或跨齿编号接缝不能直接算术平均。三维核查应输出带主动/从动齿号、面法向、载荷步和接触斑的视图。

## 4. 梁弯曲与剪切数量级筛查

矩形等截面悬臂，长度 L、宽 b、弯曲方向厚度 t、自由端横力 F，均采用一致单位：

```text
A=b*t; I=b*t^3/12; G=E/(2*(1+nu))
sigma_b_root=F*L*(t/2)/I=6*F*L/(b*t^2)
tau_average=F/A; tau_max_rectangle=1.5*F/A
delta_b=F*L^3/(3*E*I)
delta_s=F*L/(kappa*G*A)              # kappa=5/6 为常用矩形近似
delta_tip=delta_b+delta_s
```

该筛查可检出单位、力臂、截面方向和刚度数量级错误。真实轮齿为变截面，含圆角、轮体柔度、分布载荷与三维约束，不能将梁根名义弯曲应力当作 ISO 齿根应力或 FE 圆角峰值的精确金标准。体积分点 von Mises、主应力与梁正应力须明确区分。短粗梁的剪切贡献应保留；小挠度和线弹性资格需证据。

## 5. 刚度、参考态与自由体平衡

割线刚度 `k_sec=(F-F_ref)/(delta-delta_ref)`，切线刚度 `k_tan=dF/d(delta)`。两个邻近载荷点的有限差分是弦/增量刚度估计，只有扰动收敛且接触状态光滑时才近似切线。预载、间隙闭合和接触斑迁移会使两者显著不同；应同时保存原始位移与参考态，不能为贴合理论而任意扣除闭合位移。

同一能量共轭模式下 `F=T/rb`、`delta=rb*theta`，故 `k_linear=k_rotational/rb^2`。需用 rad 和 N·mm；N/mm、N/um、按单位齿宽的 N/mm² 均不可混写。M37 的 `Fn_per_b / (rb1*theta*1000)` 是按齿宽和 um 归一的总位移割线量，不能标成切线刚度。

平衡核查从各个隔离体实际外载、约束反力和对侧接触力构造 `sum F`、`sum M_O`，保持统一坐标、符号、单位及力矩原点；原点变换为 `M_O'=M_O-(O'-O) cross F`。系统整体中内接触力抵消，不能重复计数。比较实际从动轮扭矩与理想 T1*rb2/rb1 只是理想传动比核查，不能替代自由体残差。动态问题必须计入惯性项。

约束 rank/刚体模态、接触激活和反力路径要共同审查。仅 SPD 的降阶柔度矩阵、互补残差小或总载荷守恒，不足以证明 FE 几何、边界和柔度来源正确。导入柔度需记录模型、工况、自由度定义及有序 site_ids。

## 6. 异常到判别实验

| 观测 | 需要保留的证据 | 下一步判别实验 | 不能直接得出的结论 |
|---|---|---|---|
| 尖角/刚性耦合边界峰值随细化持续增长，区域积分力稳定 | 峰值位置、未平均值、局部 h、几何半径、相同区域积分 | 有限圆角/实际接触面积模型与固定物理区域指标比较 | 单个最大值已收敛或材料一定失效 |
| 齿顶一两个单元承载，压力尖峰 | 实际激活单元、接触间隙、斑宽/h、面法向 | 只细化实际斑区，核查齿相位/背面与初始穿透 | 必然求解器错误 |
| 载荷下大刚体移动、近零反力、零接触 | 约束 DOF、初始间隙、接触状态、刚体模态 | 保留物理载荷路径的最小约束诊断与接触闭合跟踪 | 加任意固定约束即可修好 |
| 斑区移出原加密区或移动至齿宽边缘 | 每步接触位置、局部网格、距边缘距离、按宽度力分布 | 追踪激活区并重划同等局部精度网格 | 全局节点数更多即更精确 |
| 相同面载系数但一个中央集中、一个边缘集中 | 空间位置、端部载荷占比、分布形状 | 保持总力和标量峰值、改变位置的对照 | 单凭面载系数能识别边缘接触 |
| 峰值/位移在网格序列中振荡 | 同模型同量同区域，局部 h 与每级解 | 增加可信网格级别并检查拓扑/采样一致性 | 取观测阶绝对值后可做收敛外推 |
| 罚刚度变化导致结果改变 | 穿透、迭代收敛、网格、接触拓扑 | 固定模型的罚刚度敏感性及能量/平衡核查 | 线性 1/K 外推必然等于物理解 |
| 数值残差小但理论偏差大 | 各输入语义与理论适用域、真实输出字段 | 先比量纲/加载/接触分配，再比理论 | 数值收敛可证明建模正确 |

网格研究需相同几何、材料、载荷、接触算法、输出定义、比较区域与解状态，记录实际斑区/齿根 h、单元阶次和质量。总节点数排序不可替代 h 序列。Richardson 外推只适合足够级别、可信渐近区与适当误差模型；负观测阶、振荡、噪声、奇异峰值应报告不确定/不适用，不能用绝对值伪造正阶。非线性收敛和网格收敛是独立检查。

## 7. 必须能够区分的负例

| Fixture | 应触发的判定 |
|---|---|
| Hertz q/E/nu 含 NaN/Inf，E<=0，nu>=0.5 或 <=-1 | 输入无效，不能产生 pass |
| q=0；q<0 | 前者显式零载，后者拒绝该压缩接触公式 |
| 曲率和为零/负或以 abs 修正符号 | 非共形线接触资格失败 |
| 点接触结果送入线接触接口；总力当 N/mm | 模型身份或量纲不匹配 |
| q×4 后 p0×4；相同实体输入 mm→m 未变 E 数值 | 变形/单位检查失败 |
| 每个同时啮合齿对都使用总 Fn | 载荷分配和全局力平衡失败 |
| 外齿参考 Ft 和 alpha_w 混用；斜齿 alpha_n 当 alpha_t | 几何/力学定义失败 |
| 缺 yield 却标弹性资格通过；只凭 p0>yield 宣称塑性 | 缺失证据或失效准则不匹配 |
| 空 geometry_checks={}，程序用 all(values()) | 必需检查未执行，不能通过 |
| 接触压力基准与最大体 VM 对比 | 命名量不匹配 |
| 固定 100–3000 MPa 作为所有齿轮有效性门 | 无适用依据，不是通用验收规则 |
| 梁厚度与宽度交换后结果仍不变 | 弯曲轴/截面定义错误 |
| 预载状态总位移割线标为切线 | 刚度类型和参考态错误 |
| 全局节点数增加但实际接触区 h 不变 | 不能据此宣布接触网格收敛 |
| 相同峰值和总力但斑区从中央移至端部 | 位置检查应区分边缘风险 |
| Richardson 负阶被 abs 变为正阶 | 不应产生有效外推证书 |
| 理想扭矩比例正确但实际反力符号错 | 自由体平衡应失败 |
| 结果文件存在/后处理完成但未检查收敛 | solved/converged/physically_valid 不得自动通过 |
| 齿编号跨周期接缝直接平均而选中背面 | 接触面身份/三维位置检查失败 |

这些负例应使用小型确定性输入，能在无商业求解器环境运行；它们验证审查机制是否拒绝错误，不能替代商业求解器实际作业和模型验收。

## 10. 后续快照复核与 M37 适配边界

父任务补充了 `review.py` 的三类 fail-closed 检查：返回码必须是真正的 `int`（排除 bool）、标量平衡残差要求同一自由体同时有 force/moment、且每项绑定自由体、原点/尺度、定义和原始来源 hash；网格身份现在包含 quantity/unit/support_region/extraction/load_state；理论比较要求非空定义和 actual/predicted 身份一致。现有 23 项测试全部通过，M37 历史重放的 `replay-summary.json` 中三例 native matrix 通过、ph10 真实接触局部网格触发为 FAIL、理论与三层网格不足保持 UNKNOWN、未调用求解器。上述证据只证明诊断管线行为，不代表 FE 工程验收。

对当时快照的 `fea_readiness/adapters/m37.py` 及其只读旧预检的进一步静态审阅曾发现两个 profile-specific 绑定缺口（见本节原始记录）：

1. `semantic_preflight.rigid_check` 用边界自由度的**键**构造刚体模态秩，但没有检查边界行给出的位移值。将固定轮/孔的一个 BOUNDARY 值改成非零，矩阵秩和 `ready_for_diagnostic_solve` 可能仍保持通过；旧 `check_before_solve.py` 也只要求 `OP=NEW`，没有验证固定值、目标节点集和每步意图。该门应按步骤保存并比较 `(set/node,dof,value)`，把非预期非零位移、遗漏轮体固定或错误的 `OP` 报 UNKNOWN/FAIL。刚体代数仍不是三维刚度矩阵稳定性证明。
2. `m37.py:30` 只验证 `meta['pairs']` 非空且数量等于名义理论接触对数；几何审计会用 metadata 点寻找最近面，但没有逐对绑定 `k/s/point` 到 `s_ref`、phase 和理论生成的对应位置。若把 metadata 对换为另一个仍落在表面附近的有效点，接触几何局部筛查可能仍通过，然而理论相位、载荷位置和 FE 面不是同一个物理状态。应在已知 M37 profile 中逐项比较 pair 的 index、作用线坐标、理论点（含周期 unwrap）和 deck surface element/side，必要时对相位和 source case 建 hash/manifest。

次要观察：`review.contact_check` 已要求 active element 记录具备 element/face 和原始来源 hash；source role/path 与字段范围的逐项 manifest 仍待补齐。`theory_comparison` 的身份字段没有单独的 topology/method 字段，当前由 `applicable` 断言补足；profile 外适用性断言必须带来源，不能由数值相等推导。

这些问题是已知 M37 适配器的语义收口项，不应扩张为通用 Abaqus/CalculiX 解析器要求。可用最小变异 fixture 验证：只改边界值但保持元素、材料和 deck hash 其他项；只改一条 `meta.pairs[*].point` 到另一个实际表面点并更新 metadata hash。两个 fixture 都应阻断 diagnostic dispatch，且旧输入三例仍保持原有重放结论。
