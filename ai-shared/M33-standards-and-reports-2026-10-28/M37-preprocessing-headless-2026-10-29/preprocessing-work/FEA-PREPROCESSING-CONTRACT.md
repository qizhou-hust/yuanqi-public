# M37 前处理与结果语义契约

本轮已把前处理要求落实为脚本、负例、原始结果复核和可旋转三维辅助视图。检查范围为现有 M37 CPE6 平面应变、无摩擦罚接触、两步加载模型；未知模型不能沿用这份“通过”。所有计算均通过 CLI / COM 无头执行，不操作桌面鼠标或键盘。

## 求解前检查

| 检查 | 机器证据 | 不可越过的范围 |
|---|---|---|
| 输入身份 | INP、meta、题目与来源 SHA256；单次检查绑定输入 | 哈希只证明文件一致，不证明物理正确 |
| 单位 / 厚度 | N、mm、MPa；1 mm 切片；25 Nm 按 30 mm 齿宽归一 | 二维切片不能解释三维端部或轴向分布 |
| 材料 / section | 按每个 section 的材料引用核 E、ν；拒绝悬空或错误材料 | 不只看第一张 ELASTIC 卡 |
| 接触区域 | 面必须属于正确齿轮外边界；理论点到二次曲边距离、相对间隙、外法向 | 局部点检查不是全域无穿透证明 |
| 周期几何 | 跨 ±π 齿号先连续展开；核原相位与理论点不变 | 普通整数平均会误选到轮背面 |
| 约束与初态 | 各步刚体约束秩、MPC 依赖 DOF 冲突、第二步位移释放 | 不等同完整刚度矩阵稳定性或所有内部机构检验 |
| 载荷 | 带符号合力 / 合矩、主节点 DOF、各步归属、P02跨网格固定作用矩 | 力相等不代表加载状态相同 |
| 高阶网格 | TRI6 Jacobian 二次多项式的顶点/边/内部驻点最小值；共享中点、非流形边 | 浮点代数检查；正 Jacobian 不证明应力收敛 |
| 全域初态辅助 | ph10整轮曲边按4/8/32子段离散的多边形相交筛查；记录弦偏差 | 数值筛查不能升级为曲边精确无穿透证明 |

`check_before_solve.py` 在所列检查失败或不能解析时返回 **2**，通过返回 **0**，不自动启动求解器，也不授予模型验收。用于当前工作目录：

```powershell
& 'D:\anaconda3\python.exe' -B -X utf8 preprocessing-work/check_before_solve.py --input m37-l3-periodic-diagnostic/runs/L3/L3_C001_G1_ph00_d12.inp --report preprocessing-work/check-ph00.json
if ($LASTEXITCODE -ne 0) { throw '前处理未通过，不提交求解' }
```

在提交前必须确认 INP SHA256 与报告一致。旧控制器、冻结输入和验收门没有被悄悄改写。`verify_pre_solve_matrix.py` 检查原始32份/诊断相位输入：原10个错误相位应失败、原6个正确相位和修复16相位应通过。独立审阅又以反向扭矩、错误材料及悬空材料引用作负例，已修补底层检查器的两处漏检。

## 求解后必须返回实际接触区域

仅在理论接触点周围检查网格不够。新增 `extended_preflight.py` 从最终 DAT 反查实际受压单元，并报告每条边的尺寸与目标 h 之比、距理论点距离。ph10 高压单元7779边长约0.1574 mm，目标 h约0.003903 mm，约40倍；原 h_check只检查理论点附近36条边，无法发现这个齿端。

这里触发“实际接触区需要额外网格收敛”审阅，**不删去该压力、不把它认定为错误结果，也不据此宣称网格已修复**。该点峰压5283.265 MPa，理论在啮齿局部峰压约571.003 MPa；初态41个采样点的最小局部正间隙0.001420295 mm。物理加载后的额外齿端接触、接触离散与局部网格影响仍需受控细化验证。

## 平衡、参考对比与验收分开

官方CalculiX源码确认：CF力矩关于全局原点；其末行normal force是总合力与面积平均法向的点积，不等同于∫p dA或理想T/rb。比较力矩前先换到同一原点、确认主从面符号。

ph10接触矩换到轮心后与轮孔反力矩相差约1.571e−5，接触矩对输入矩差3.604e−5。原0.00295634、0.00300851分别是对理想传动比、理想法向力的差，保留在原验收中。真实平衡好并不能消除理想模型偏差。

刚度继续明确为总位移割线刚度，不能把末增量弦刚度或切线刚度替代。低载修正、孔支承、位移参考的等价性没有闭合；不能为追平FE而换参考值。
