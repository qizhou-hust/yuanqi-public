Register the KISSsoft COM server 
2.1 General 
KISSsoft offers the possibility of remote control via a COM interface. In Windows, COM (Component Object 
Model) allows software components, written in different languages, to communicate. It can easily be accessed 
from Excel (Visual Basic), Python, C++, Java, etc. This tutorial shows how to use the interface with Excel and 
Python. 
 
KISSsoft provides two COM interfaces, which can be registered simultaneously: 
▪ 
KISSsoftCOM: Compatible across all KISSsoft releases. Existing macros or code do not require 
modification when updating to a new KISSsoft version - only the COM server needs to be re-registered. 
This interface will be used in this tutorial. 
▪ 
KISSsoftCOM20xx: A version specific COM interface, e.g. KISSsoftCOM2026 only works with KISSsoft 
Release 2026.

Sub Tutorial()

Set ksoft = New KISSsoftCOM.CKISSsoft 
 
'2. load calculation module 
Call ksoft.GetModule("Z012", True) 
 
'3. show UI 
Call ksoft.ShowInterface(True) 
 
'4. release calculation module 
Call ksoft.ReleaseModule 
 
End Sub

How to find variable names 
The connection to the COM server was successfully tested. KISSsoft can now be remote controlled. To access 
the parameters, you need to know the variable names. 
This section provides some general advice to help users to find variable names more easily. A number of 
sources and methods are available for finding variable names. 
▪ 
Variables directory in the manual, which contains a selection of common parameters.  
▪ 
Variable list in the software, which is available in each calculation module via Script Editor → Calculation 
variables. 
 
Figure 11: Calculation variables 
▪ 
Comparison of calculation files (Section 4.1). 
▪ 
Searching for variables in the report templates (Section 4.2). 
4.1 Comparison of calculation files 
This method is especially useful for input variables in the graphical user interface. If you’re looking for result 
variables, please continue in Section 4.2. 
 
1. Save two (almost) identical calculation files, which only differ in the inputs you’re interested in.

Remote control KISSsoft 
In this section, a simple example macro is used to demonstrate how KISSsoft is remotely controlled. For this 
purpose, the information gathered in the previous sections is used. The goal is to set the application KA to 1.5 in 
an existing calculation file and then retrieve the calculated root safeties of both gears. 
 
Note: Various examples are available on demand (kisssoft.support@gleason.com). 
 
The following steps are necessary: 
▪ 
Initialize the KISSsoft COM object. 
▪ 
Load the cylindrical gear pair calculation module (Z012). 
▪ 
Load an existing cylindrical gear pair file. 
▪ 
Set the application factor KA = 1.5. 
▪ 
Run the calculation. 
▪ 
Read the calculated root safeties of both gears. 
▪ 
Close the KISSsoft module. 
 
Initialize the KISSsoft COM object: 
 
'initialize KISSsoft COM object 
Dim ksoft As KISSsoftCOM.CKISSsoft 
Set ksoft = New KISSsoftoCOM.CKISSsoft 
 
Load the cylindrical gear pair calculation module: 
 
'load calculation module 
Call ksoft.GetModule("Z012", True) 
 
Load an existing cylindrical gear pair file with the function LoadFile(). Use the path of the file location. 
 
'load file 
Call ksoft.LoadFile("C:\KISSsoft 2026\example\01 Spur (ISO 6336).Z12") 
 
Set the application factor KA = 1.5 with the function SetVar(). The Variable for KA is ZS.KA, as shown in section 
4.1.

'Set application factor KA 
Call ksoft.SetVar("ZS.KA", "1.5")

5.2 Code in Python 
 
import win32com.client as client 
 
#initialize KISSsoft COM object 
ksoft = client.Dispatch('KISSsoftCOM.KISSsoft') 
 
#load calculation module 
ksoft.GetModule('Z012', True) 
 
#load file 
ksoft.LoadFile('C:/KISSsoft 2026/example/01 Spur (ISO 6336).Z12') 
 
#set application factor KA 
ksoft.SetVar('ZS.KA','1.5') 
 
#run the calculation 
ksoft.Calculate() 
 
#get root safeties 
SF1 = float(ksoft.GetVar('ZPP[0].Fuss.SFnorm')) 
SF2 = float(ksoft.GetVar('ZPP[1].Fuss.SFnorm')) 
 
print(f'SF1: {round(SF1,2)} \nSF2: {round(SF2,2)}') 
 
#release calculation module 
ksoft.ReleaseModule()
