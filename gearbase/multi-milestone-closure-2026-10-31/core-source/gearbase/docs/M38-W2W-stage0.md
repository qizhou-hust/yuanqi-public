# M38 W→W Stage 0

`gearmath.gear.flagship_w2w.run(parameters)` executes the archived M31 SPEC §2-C/D and §3 W→W discrete geometry, constant-friction efficiency and convection model. `verify(parameters, candidate)` independently re-enumerates the same active model and checks exact membership in the returned candidate set. It is not an independent physical validation. Strength, scuffing, wear, shafts, bearings and ISO worm rating are not calculated. No Formula graph exists for this model in the current kernel; the equations are implemented in the domain module.

All input keys are mandatory: `a1_mm`, `a2_mm`, `n1_rpm`, `target_ratio`, `rho_v_deg`, `t_out_nm`, `z1_options`, `ratio_band`, `k_w_m2k`, `area_m2`, `t_oil_max_c`, `t_amb_c`, `max_candidates`. Units follow names; temperatures are Celsius and torque Nm. Missing, extra, nonfinite, or invalid values raise ValueError. Search uses M31 module and q series, integer tolerance 1e-6 and the original 1,000,000 pair cap; truncation and cap status are reported. Thermal failures remain candidates.
