# M37 FEA 题目说明（L0–L3 验证阶梯）

依据：gearbase `docs/分路设计报告/L3-fea-tool.md` 中的 §1.3 证书契约、§3 验证阶梯和 §4.2 修复策略（F0–F2）。各题参数在 `cases/*.json` 里，参考值在 `expected/*.json` 里。下文每题都按同一顺序写：目的、几何、材料、网格、边界条件、载荷、接触、提取量、验收线。

**通用约定**

- 单位：N、mm、MPa。全部题目都用二维平面应变模型，厚度取 1 mm，所以载荷都是"每毫米齿宽"的量。ccx 内部会把 CPE6 展开为 C3D15，把 CPE8 展开为 C3D20。
- 材料：线弹性钢，E = 206000 MPa，ν = 0.3。L0–L3 都用同一种材料。
- 加载：一律用力或扭矩控制。L0c、L1、L3 有接触，分两步加载：第 1 步只施加一个很小的位移，让接触闭合（这一步的结果不采用）；第 2 步用 `*BOUNDARY,OP=NEW` 撤掉这个位移，再施加已知的力或扭矩。所有结果都取第 2 步末的值。不使用转角控制，因为 M31 中 11 GPa 的问题就出在转角控制上。
- 应力取法：齿根应力只用积分点值。脚本请求 `*EL PRINT … S` 和 `COORD`（积分点坐标），在每个单元内按积分点做多项式最小二乘，再外推到表面节点，**不做节点平滑**。如果你的 ccx 不支持 `COORD`，脚本会自动关闭这项请求，改用积分点最大值，并在结果中记一条警告。
- 网格：用 gmsh 生成二次单元，曲边的中间节点落在解析曲线上。每题至少 3 级网格，相邻两级的尺寸比为 1.5。单元质量要求 gmsh 缩放雅可比 minSJ > 0.3。
- 外推：Richardson 外推取最细的三级网格，先求观测阶 p；如果三级结果不单调，或者 p 不在 0.5–5 之间，就改用 p = 2，并记下原因。penalty 外推按 f(K) = f∞ − c/K 做三点最小二乘。
- 几何来源：齿形由带齿顶圆角的基本齿条按展成运动解析生成（`scripts/gear_geom.py`），不读任何 CAD 文件。本环境已经核对过：14 个 L2 点在 30° 切点处的 sFn、ρF 以及 HPSTC 直径 den，与 gearbase（ISO 6336-3 方法 B）的计算值相对差不超过 2e-9（运行 `selfcheck.py` 可复核）。

## L0 补丁 / 单元检验（含 L0c 接触补丁）

| 项 | 内容 |
|---|---|
| 目的 | 确认 ccx 的单元、积分点输出、`*EQUATION` 和两步加载流程本身是对的；同时探测 ccx 是否支持 `*EL PRINT COORD` |
| 几何 | L0：10 × 4 mm 矩形。L0c：两块 10 × 2 mm 矩形上下叠放，接触面两侧网格不匹配 |
| 材料 | 钢，E = 206000 MPa，ν = 0.3 |
| 网格 | L0：非结构网格，h = 2.0 / 1.2 / 0.7 mm，内部偏心处局部加密，故意造出畸变单元；CPE6 与 CPE8 各做一套。L0c：h = 1.0 / 0.6 mm，CPE6，上下块节点数不同 |
| 边界 | L0：左边 u = 0，原点 v = 0。L0c：下块底边 v = 0，两块左边 u = 0 |
| 载荷 | L0：右边施加均布拉应力 σ = 100 MPa，按一致节点力（二次边按 1/6、2/3、1/6 分配）。L0c：上块顶边施加均布压力 q = 50 MPa |
| 接触 | L0c：面-面接触，penalty 线性压力-过盈关系，K = 10·E/h；另有一个 `TYPE=MORTAR` + `HARD` 变体，作为实验 |
| 提取 | 全部节点位移、全部积分点应力、反力合力、接触应力表；同时记录 ccx 每个单元实际输出的积分点数 |
| 参考 | 平面应变单轴精确解：u = σ(1−ν²)x/E，v = −σν(1+ν)y/E，σzz = νσ。接触补丁的精确解是 p = q |
| 验收 | 位移误差（取最大值，再除以最大位移）< 1e-6；积分点应力误差 < 1e-5；力平衡 < 1e-5；接触压力误差 < 1e-4（取所有积分点） |

注：设计文档要求力平衡 < 1e-10，但 ccx 的 .dat 文件只输出 7 位有效数字，所以这里放宽到 1e-5。位移的验收线 1e-6 保持不变。

## L1 二维 Hertz 圆柱接触

| 项 | 内容 |
|---|---|
| 目的 | 在已知解析解的情况下，检验接触离散、penalty 外推和 mortar 三种做法 |
| 几何 | 两个半圆柱，R1 = R2 = 10 mm。上半体的平底位于 y = +10，下半体的平底位于 y = −10，两者在原点接触 |
| 材料 | 钢，E = 206000 MPa，ν = 0.3 |
| 网格 | CPE6。接触点附近半径 2.5a 以内的单元尺寸 h = a/8、a/12、a/18（a = 0.0750 mm），向外线性增大到 R/8 |
| 边界 | 下平底 v = 0，其中心节点 u = 0。上平底所有节点的 v 用 `*EQUATION` 绑到一个参考节点上（相当于刚性压板），该参考节点 u = 0 |
| 载荷 | 在参考节点上施加 −100 N，即线载荷 q = 100 N/mm（力控制）。第 1 步先给一个闭合位移 |
| 接触 | ① penalty：面-面，K = α·E/h。网格研究取 α = 10；在最细网格上另做 α = 5、20，用于 penalty 外推。② MORTAR：做同样三级网格，作为实验 |
| 提取 | 峰值接触压力（取 .dat 中积分点的最大值）、接触合力、反力。半宽 a 用 .frd 中节点 CPRESS 做椭圆拟合；如果拿不到 .frd，就用接触面积统计量 |
| 参考 | p0 = 848.86 MPa，a = 0.07500 mm（Johnson 解，见 `expected/L1_hertz.json`） |
| 验收 | 三级网格中最后两级之间的变化 < 2%；把 penalty 外推后的修正加到 Richardson 外推值上，峰值误差 < 3%；半宽误差 < 5%；接触合力误差 < 1e-3。penalty 与 mortar 两条路线只要有一条通过即可 |

## L3 直齿副：σH0、单齿刚度 c′、啮合刚度 cγ

| 项 | 内容 |
|---|---|
| 目的 | 在名义载荷下（KA = KV = KHβ = KHα = 1），把直齿副接触 FE 的接触应力和刚度与 ISO 6336-2、ISO 6336-1 的名义值对比 |
| 算例 | **C001 第一级（G1）**：z = 20/36，m = 2，αn = 20°，x = 0/0，haP* = 1，hfP* = 1.25，ρfP* = 0.38，b = 30，T1 = 25 N·m（数据来自 gearbase `data/m31/golden/C001`）。TR30 例 1 是斜齿，不适合做二维直齿题，所以按"二选一"选了 C001 |
| 几何 | 两个完整齿轮（全部轮齿），中心距 a_w = 56 mm。为了让非工作齿面留出侧隙，每个齿轮都按齿厚减薄 Asn = −0.02m 展成，法向侧隙约 0.075 mm（已在 selfcheck 中核对）。内孔直径取 0.4d |
| 材料 | 钢，E = 206000 MPa，ν = 0.3 |
| 网格 | CPE6。在每个啮合点半径 3a 以内，h = a/8、a/12、a/18（a = 0.0468 mm，即节点处的 Hertz 半宽），向外 3 mm 内过渡到 0.5m；工作齿面上 h ≤ 0.08m |
| 边界 | 大轮内孔全部固定。小轮内孔用 `*EQUATION` 约束为绕轮心的刚性小转动；主节点取在 (r_bore, 0)，其 u = 0 |
| 载荷 | 第 1 步用小转角让接触闭合；第 2 步在小轮主节点上施加 −T/r_bore 的力，等效为顺时针扭矩 T/b = 833.33 N·mm/mm（扭矩控制） |
| 接触 | 面-面 penalty，从面是小轮工作齿面 + 齿顶（接近啮合区的 5 个齿），主面是大轮对应的面；K = α·E/h。另在最细网格上做一个 MORTAR 实验变体 |
| 相位 | 节点 C 处的相位（单齿对）用来求 σH0 和 c′，做三级网格研究，并在最细网格上用 α = 5、10、20 做 penalty 外推。另取 16 个相位，s = s_A + (j + 0.5)·pb/16，用 a/12 网格；8 相位均值取其中偶数 j 的 8 个 |
| 提取 | 峰值接触压力；小轮转角 θ；沿啮合线的变形 δ = rb1·θ；刚度 c = (Fn/b)/δ；大轮内孔反力矩与接触合力（用于守恒检查） |
| 参考 | 见 `expected/L3_C001_G1.json`（gearbase 实算）。σH,C(Hertz) = σH0/Zε = 602.73 MPa，σH0 = 536.33 MPa（含 Zε = 0.890，仅作信息）。c′th·CB = 15.68 N/(mm·µm)，ISO c′ = 10.08（含 CM = 0.8 和低载系数，仅作信息）。cγα,th = c′th·CB·(0.75εα + 0.25) = 23.03，ISO cγα = 14.80（仅作信息） |
| 验收 | σH 与 σH,C(Hertz) 之比 ∈ [0.92, 1.08]；c′ 与 c′th·CB 之比、cγ 与 cγα,th 之比 ∈ [0.8, 1.2]；三级网格中最后两级之间的变化 < 2%；8/16 相位均值的变化 < 3%；扭矩守恒和接触合力误差 < 1e-3；节点相位必须是单齿对啮合 |

σH 的比较口径：节点 C 处只有一对齿啮合，FE 峰值本来就是这对齿承受全部载荷时的 Hertz 峰值，所以应该与 Zε = 1 的值比较。拿含 Zε 的 σH0 去比（M30 用的就是这种不同口径的比较），会系统偏高约 12%。c′ 的比较口径：FE 用的是理想几何、没有误差，所以应该与理论刚度 c′th·CB 比较，而不是与含经验系数 CM = 0.8 的 c′ 比较。
