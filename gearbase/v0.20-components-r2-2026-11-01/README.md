## 数据口径

H/P/W/B四种原子语义类型使用一个固定角色的P，H的直齿/斜齿是下位配置。六原子域增加I/X，其中H与I共用圆柱平行父插件族，因此六个原子语义类型不等于六个父插件族。不同P角色、配方配置、参数实例、布置变体与案例证据各自有身份，不相互混加。

`topology-library.json`包含1554条抽象条目，四类型340条是其中的子集。工业/空间/详细评级均保持OPEN。报告观察器只展示四类型子集；精确工业结构先例过滤为0，表示尚未做逐条映射，不是这些结构工业不存在或物理不可行。

库文件中的可选“W至多一次且位于末级”政策仅是计数实验，未启用为基础规则，不会从本报告默认语法排除W→W。<=4是项目范围，不是工业通用上限，也不是汽车挡位数。
