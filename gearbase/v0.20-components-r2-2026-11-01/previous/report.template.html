01 / THE DECISION

可以用，但先按工程计算工作台来用。

当前最合适的产品定位是：工程师主导、来源可追溯的圆柱齿轮计算、有限域优化与系统校核底座。可以初步冻结这层接口和数值基线，开展真实工程试用；还不能把“输出转速、转矩、空间”直接变成已完成全系统校核与制造验收的齿轮箱。

可立即开展

计算与可控方案迭代

已知输入和方法选择齐备的圆柱副校核；公式追踪、灵敏度；声明域内尺寸优化；显式输入下的轴、轴承、键等检查；预览与受控提交。

可用于前期筛选

固定架构 Stage0

H2、双蜗杆、双行星的运动学候选枚举和有限约束筛选。返回的是概念候选，仍需详细载荷、强度、支承、空间与热校核。

尚未到达

一键成熟整机交付

通用跨架构规划、完整工况传递、所有传动族详细评级、箱体与装配、变位齿根 CAD、合格 FE、制造图与独立工程审阅的总闭环。

建议冻结两件事：冻结 v0.20 已重放的数学与工具契约；把本轮案例目录、真实失败和边界说明作为试用基线。后续优先打通一个真实需求的纵向闭环，再增加传动族。数学底座稳定，不意味着应用范围停止扩展。

02 / THE WHOLE SYSTEM

终局是一套需求驱动的工程生成系统。

用户输入的是外部需求，系统应负责提出结构、传递工况、派生零件和证明方案适用范围。最重要的结构变化是：在现有数学核上方补齐需求合同 → 有序拓扑 → 全系统设计，而不是让语言模型直接拼齿数、CAD 或安全系数。

输入与澄清

部分实现

转速/转矩、寿命工况、空间、轴关系、精度、成本与最小裕量。缺项具体追问。

拓扑规划与方案集

关键缺口

简单有序组合、级数/比、轴系方向、候选去重；同一需求比较不同架构。

系统设计唯一真源

局部真源已实现

目前圆柱副与投影管理较完整；系统输入与外链仍需统一设计图和版本。

功率流与载荷谱

当前仅固定模型部分派生

现有部分n/T与简化损耗/热可算；目标还包括全工况正反驱、三向力、冲击和载荷谱寿命贯通。

数学计算与详细校核

选定范围可运行

圆柱齿轮、轴、轴承、键、过盈与部分失效模式；缺数据或模型明确阻断。

优化与稳健备选

有限问题已验证

离散变量、约束、灵敏度、Pareto；尚需统一工况贯通、架构层排序与裕量。

CAD、箱体与制造

总成闭环不足

齿廓/产形齿根、轴承配合、箱体/密封/润滑、全运动干涉和制造图。

高保真与外部验证

FE 资格未通过

严格读取和真实结果已有；FE 失败点、独立工艺评审、油品与试验来源仍待关闭。

用户选择与变更传播

当前仅数值DAG与局部CAS

终局目标：自然语言变更后，相关数值、CAD/FE与制造产物自动失效、重算或重建，并显示状态。

目标主链：需求 → 拓扑候选 → 同源参数与工况 → 分级校核/优化 → CAD/FE/制造 → 用户选择。目标反馈：每次修改回到同一个源，旧证据自动失效；当前尚未实现跨CAD/FE/制造的统一自动传播。

输入合同还应包含什么

输入动力源的工作区间或可选范围；输出载荷/速度及方向；额定、短时峰值、堵转/冲击与停机保持；工作制/寿命；轴位置与允许偏置；外形与禁入区；环境/润滑；效率、噪声、间隙、成本和维护偏好。

只给输出转矩和转速，可以定义输出功率需求，不能唯一确定输入电机、级数与各级效率。缺这些约束时应输出有标注的候选域。

“尽量简单”要变成可审计目标

优先级建议：满足硬约束 → 减少未验证模型 → 少级数与少零件 → 留足最小裕量 → 体积/损耗/成本折中。用透明评分和 Pareto 集给出数个不同架构的备选，不用一个未经确认的加权分掩盖工程取舍。

这是下一阶段建议，不是当前优化器已经使用的目标。

03 / CAPABILITY BOUNDARIES

优势在可追溯的底层，短板在跨模块的总闭环。

本轮以代码入口、当前会话输出与固定哈希的历史凭据核查。模块存在、测试通过、工程范围覆盖分开评价；商业软件对拍也只覆盖实际输入与方法分支。

已验证运行部分 / 有范围未覆盖 / 被阻断历史证据，本轮未重求解建议建设
@@CAPABILITY_ROWS@@
能力判断现在可以做到边界 / 距终局的缺口

应继续保留的优势

  • 量纲、公式注册、依赖图、灵敏度与纯数学优化层分离，方便解释和回归。
  • 作者输入、投影、来源与哈希分开；预览/CAS 保护一致性，来源缺失不会自动变成“通过”。
  • 有限域全枚举对拍和商业字段回放，较易发现口径差异；FE 原始字段、身份与失败可重贴。
  • 支持无头工具链，适合语言模型调用与批量比较；可渐进扩展工程域。

不应据此推导的能力

  • 数学层统一，不等于所有系统组件和外部 CAD/FE 已共用同一可编辑源。
  • 样例和边界域通过，不等于全材料、全传动族、全工况适用。
  • 优化返回 feasible，不等于自然语言原需求中的所有条件都已进入该优化。
  • 记录 SHA、CAS 和来源标签，不等于认证过的工程师身份、供应商数据或独立审批。
04 / THE BOTTLENECKS

首要难点是工况、拓扑和系统数据的贯通。

本轮实测反例：两份单级直齿需求把转矩从 40 改为 400 N·m、转速从 1000 改为 3000 rpm，并调整寿命、材料、空间。详细校核的接触安全系数会改变，但模板优化调用与 IR 保持相同；两次仍返回相同宽度/中心距。编译结果已声明 unapplied、post_checks 和固定 C001 适用范围。这个模板的 feasible 不能解释为实际新需求已经可行。

@@COUNTEREXAMPLE_ROWS@@
反例观察需求 A需求 B解释

本轮原始响应与脚本：requirements smoke · 架构审计。安全系数属于该实际单副校核，不是另一次全系统验收。

1. 还没有通用架构生成器

目前先选择 H2/W2W/P2 再进入各自搜索。几千个齿数组合仍可能只有一种拓扑；用户最关心的“一个需求有哪些实现方式”尚缺统一入口、比较合同与跨族验证能力矩阵。

2. 输入完整性决定系统能否算完

C001 与 H2 的真实轴布置、材料、支承和寿命要求仍不齐；蜗杆/行星详细模型又受冻结限制。缺工程输入与缺模型是两类问题，不能靠代填默认值一起抹掉。

3. 最优与成熟是不同的目标

当前局部最优受声明域、保持系数和近边界安全裕量限制。整机还要考虑制造分辨率、负载谱、误差/温升/磨损、标准件、支承刚度和空间冲突。需要鲁棒备选和不满足项，而不仅是最小体积数值。

4. CAD / FE / 真实工程证据还没闭合

变位齿廓/产形齿根、总成布置与箱体尚不完整；FE L2 固定矩阵失败，L3 仅派生试算；工艺审阅、40题工程师金标、油品试验等仍有外部依赖。

06 / SAME DEMAND, DIFFERENT DESIGNS

用同一需求做对照，才知道系统能否提出真正的备选。

建议将现有案例重新组织为三个互补集合：真实工程需求集验证能不能解决用户问题；外部数值参照集验证怎么算；缺陷与变更集验证不会退化或凭空补参数。原有 50 派生题、K01–K05、TR30、三旗舰和 FE 题目各有用途，不能混为同一类“案例数”。

需求合同

保存不可变的输出性能/载荷谱、动力源、轴系关系、空间禁入区、寿命环境、最小裕量与制造偏好。每个字段带单位、来源和状态；存在 unknown 的题允许澄清，不允许暗补。

多实现参考集

工程师为同一合同给出可接受拓扑集合与至少一个可复核参考方案；允许多个正确解。保存拒绝结构的原因，不只保存最终最优齿数。

07 / SINGLE SOURCE OF TRUTH

保留数学唯一真源，把系统结构与派生产物接上去。

当前 math-source/2 与圆柱副投影、文件 CAS 链和来源校验是值得保留的基础；系统层还有独立输入文档，CAD/FE/制造文件也未形成统一自动更新事务。需要两个图相互连接：物理系统图描述轴、端口、级和力流；计算依赖图描述每个数值如何计算及哪些证据依赖它。

一次变更的正确语义

  1. 自然语言变为结构化、带来源的变更提议，区分几何改动、工况改动和约束修改。
  2. 预览影响：哪些传动级、轴承载荷、热、CAD/FE 与制造产物会变。
  3. 在同一源版本受控提交，旧派生项标记 stale。
  4. 按依赖图重算/重建；昂贵 FE 可以排队，但不能显示旧结果为“已更新”。
  5. 输出 ready / pending / blocked / fail 及剩余行动；保留原版本可回溯。

关键不变量：应用、CAD 和模型客户端不另算一份齿轮参数；只读取版本化数学投影。依赖身份要绑定真正相关的输入与实现，不应因无关文档变化使全部证据失效，也不能漏掉材料、标准方法或外部工具版本的变动。

自然语言的权限边界：语言模型负责澄清、提出结构/变更和调用工具；工程数值由确定性模型计算。当前调用方可填写来源标签，标签和 CAS/token 不是独立身份认证。初步冻结按可信本地工作台使用；未来多用户或自主代理写入，需要服务端来源、角色与审阅证据绑定。

08 / SCREW & NUT AS A SYSTEM MEMBER

把丝杆螺母做成旋转—直线转换级。

应放入同一有序传动链，而不是单独附一个无关计算器。它的推力、速度和支承反力要反传到减速级与轴承；导程、摩擦、寿命和行程变化要重算输入扭矩、热、回驱与装配空间。

第一切片：滑动丝杆 / 螺母

建议先限定一种明确螺纹几何、材料副与润滑条件，支持固定的旋转/平移约束；显式给出导程、头数、有效/根径、摩擦模型、承压长度、支承与行程。先闭合运动、正反驱转矩、效率/热和轴向力，再接入屈曲、临界转速、PV/磨损与连接。

这个首选顺序是面向复合执行器的建议。若首个真实项目已有合格滚珠丝杆供应商数据，应按该项目调整顺序。

第二切片：滚珠丝杆

增加供应商动态/静态额定载荷、寿命、预紧、刚度、DN、支承极限转速、导程精度及污染润滑条件。滚动接触寿命与滑动螺纹磨损分为不同方法；不能复用一个通用“效率”或寿命式覆盖两者。

螺纹可否自锁、是否需要制动，应按工况和摩擦证据计算，不能只凭类型命名断言。

统一接口（建议）必须进入同一问题的内容首个验收证据
旋转输入 ↔ 直线输出转速/转矩与推力/速度/位移；运动方向；丝杆/螺母哪个旋转；约束与支承；双向功率流。速度路径与功率路径独立闭合，修改导程后两者和上游负载同步变化。
全行程与寿命工况支承间距、伸出长度、压/拉载荷、加减速、工作制、环境、热与润滑。全行程最不利屈曲/转速/载荷工况有来源；缺数据返回具体阻断项。
真实零件与装配防转导向、推力轴承、轴肩/锁紧、螺母连接、间隙预紧、保持/制动、端部止挡载荷路径。反力闭合并进入轴承/箱体；支承和止挡不依赖仅有的几何同轴圆柱。
方法与证据滚珠与滑动分别选模型；材料/摩擦/额定载荷/PV等有出处和适用域。至少一套独立算例或供应商计算对拍；不把静强度通过当作耐久结论。

工程方法路线另参见本轮核查的官方资料：@@SCREW_REFS@@。这里只规划接口与验收，不填入未经提供的设计常数。
