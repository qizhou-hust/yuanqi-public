## 2. 可恢复的轴承和密封损耗公式

等级 B，来源 S1 PDF21–25、S4 PDF22–25 与 PDF122。下式按标准所列工程单位使用，不可将 mm 改成 m 后仍沿用系数。

```text
(25) T_VL = T_VL0 + T_VLP1 + T_VLP2
(26) T_VL0 = 1.6e-8 * f0 * dm^3                  [nu*n < 2000]
(27) T_VL0 = 1e-10 * f0 * (nu*n)^(2/3) * dm^3   [nu*n >= 2000]
(28) T_VLP1 = 1e-3 * f1 * P1^a * dm^b
(30) P_VL = SUM_i [T_VL,i * pi*n_i/30]
(31) P_VD = 7.69e-6 * d_sh^2 * n
```

dm、d_sh 用 mm；nu 用 mm2/s；n 用 rpm；P1 用 N；T 用 N m；功率用 W。f0、f1、P1、a、b、额外轴向损耗项必须按轴承种类和原表取得，不能在所有轴承上套用一个默认值。

S4 的 Palmgren 公式 (2.14) 用 N mm；转为 N m 后系数 1e-7 变为 1e-10，与 S1 (27) 一致。S4 正文 (2.106) 显示密封直径一次方，但附录代码 PDF122 用 d_sh^2，S1 (31) 也明确为平方；本稿采用平方并记录文献内部冲突，不照搬论文正文。

轴承 1 空载转矩复算 0.886643 N m，对应正文约 0.886；轴承 7 为 0.559872 N m，对应约 0.560。公式 (28) 只恢复结构，未逐行认证全部轴承系数表。

## 3. 壳体热阻、辐射、自然对流

等级 B，来源 S1 PDF25–27、40、42；S5 PDF12–14 的串联热阻、PDF55–59 的辐射理论。

```text
(32) Q = Q_ca + Q_fun + Q_rot + Hdot_oil
(33) Q_ca = U * A_ca * (theta_oil - theta_ambient)
(34) 1/U = A_ca/(alpha_oil*A_oil)
           + delta_wall*A_ca/(lambda_wall*A_oil)
           + 1/alpha_ca
(35) alpha_ca = alpha_con + alpha_rad
(36) alpha_rad = 0.23e-6 * epsilon * [(T_wall+T_ambient)/2]^3
(38) eta_T = (T_wall-T_air)/(T_wall-T_ambient)
(39) alpha_K,free = 18 * h_ca^(-0.1)
                    * [(T_wall-T_ambient)/T_ambient]^0.3
```

theta 是摄氏温度，T 是绝对温度 K；温差数值可相同，但比值和立方必须用 K。A 是 m2；delta_wall、h_ca 是 m；lambda 是 W/(m K)；alpha、U 是 W/(m2 K)。原文 (34) 采用内表面积作为壁层参考面积的近似；复杂几何可直接组装各层真实热阻，不能无条件沿用平壁近似。A_ca 不计底面。

公式 (39) 是有单位约定和适用条件的经验关系，不是量纲纯粹的普适定律。来源注明空气速度小于 1.5 m/s、无散热肋片；算例用 T_wall 近似 T_oil。对新的结构，需要求解壁温或说明近似。

用 Stefan–Boltzmann 理论独立核对辐射：

```text
alpha_rad_exact = epsilon*sigma*(T_wall+T_ambient)
                  *(T_wall^2+T_ambient^2)
sigma = 5.670374419e-8 W/(m2 K4)
```

该式假定面向大等温环境、合适的视角与灰体近似；复杂辐射网络需另处理。算例 T_wall=333 K、T_ambient=298 K、epsilon=0.9，原经验式为 6.5008，理论线性化系数为 6.4305 W/(m2 K)，差约 1.1%。这支持符号与温度单位恢复，不证明两模型在任意温度都等价。

## 4. 强迫对流与肋片：明确可恢复边界

S1 PDF26–29 的公式 (37)、(40)–(48) 损坏较重，以下保留不同证据等级。

```text
(37), B: alpha_con = alpha_K,free*(1-A_air/A_ca)
                   + alpha_K,forced*(A_air/A_ca)*eta_T
(40), B: alpha_K,forced = 0.0086 * Re_eq^0.64 / Lx
(41), B: Re_eq = sqrt(Re^2 + Gr/2.5)
(42), B: Re = v_air*Lx/nu_air
(43), B: Gr = g*h_ca^3*(T_wall-T_ambient)
              /(T_ambient*nu_air^2)
(45), B: eta_fin = tanh(m*L_fin)/(m*L_fin)
```

式 (37) 按原残片、面积分区和式 (38) 温差比恢复；未取得 Funck 原研究的完整实验边界。式 (40) 的 0.0086 是原文工程单位系数，Lx 用 m；无外部数值算例闭合，不作为已认证预测公式。式 (43) 源页把 nu_air 显示为 15.6e-6 mm2/s，会造成严重量纲错误；若使用该数值应为 15.6e-6 m2/s = 15.6 mm2/s。这是 SI 一致性修正，不是声称发现 ISO 出版母版错误。热物性仍应随温度选取。

式 (44)、(46)–(48) 涉及 A_fin、A_pro、通风面积和辐射/对流权重，无法仅凭残片唯一恢复全部系数。本稿不发布猜测版“ISO 原式”。可采用以下等级 C 的标准传热替代模型（S5 §5），用于独立模型或敏感性研究：

```text
m = sqrt(h_eff*P_fin/(lambda_fin*A_cross))
Q_fin = sqrt(h_eff*P_fin*lambda_fin*A_cross)
        *(T_base-T_ambient)*tanh(m*L_fin)
Q_surface = h_eff*(A_unfinned + eta_fin*A_fin)*(T_base-T_ambient)
```

要求等截面、物性和换热系数近似恒定、横截面 Biot 数足够小、肋尖近似绝热。h_eff 是否含辐射必须与面积/视角假设一致；不要把 A_fin（表面积）当作 A_cross（截面积），也不要重复计入肋片根部面积。对流肋片公式可由教材核对，但它不自动复原 ISO 特定的面积权重修正。

## 5. 基础、轴和联轴器：用守恒约束防止伪修复

S1 PDF28–33；S5 §5 的一维肋片微分方程可提供结构性校核。

```text
theta = T - T_ambient
m = sqrt(h*P/(lambda*A_cross))
beta = h_tip/(lambda*m)
Q_base = lambda*A_cross*m*theta_base
         *[tanh(m*L)+beta]/[1+beta*tanh(m*L)]
theta_tip = theta_base/[cosh(m*L)+beta*sinh(m*L)]
Q_tip = h_tip*A_cross*theta_tip
Q_side = Q_base - Q_tip
```

这是等级 C 的等截面肋片、端面换热边界解，可用来处理基础或轴的简化导热支路。S1 (49) 的有限杆结构可由此理解，(52) 的 m_i 应具有 1/m 的量纲并含平方根。原文 (50) 的基础修正因子、(51) 的 0.62、单面散热时 m*=0.75m 等属经验设定；不能仅因量纲正确就宣布已复原或普适。

对圆柱轴，P/A=4/d，因此 (57)、(58) 的形式为 m=2*sqrt(alpha/(lambda*d))，可由几何和教材推导。联轴器热导 G_fl=lambda_fl*A_fl*m_fl*tanh(m_fl*L_fl)，则 (56) 可读作 h_tip=G_fl/A_sh。式 (67) 对应上面的 theta_tip；(68)、(69) 是端点温差算术平均近似。

重要未闭合项：源页 (53) 写 Q_rot=Q_rot1+Q_rot2，而 (54) 的残式形似包含端面热流的 Q_base。若一边将其解释为总基部热流，一边再加联轴器散热，会重复计数。工程替代实现必须遵守 Q_total=Q_base=Q_side+Q_tip；在没有清晰原式前，不把这种解释写成已验证的 ISO (53)–(55)。Dropkin 相关式 (59)–(64) 的参数范围也未在本轮独立验证。

验证脚本将上述解析解与独立有限体积离散作比较，检查三种端面换热条件；这验证微分方程解和实现，不验证真实齿轮箱的换热系数。

## 6. 冷却油与温度迭代

```text
(70), B: Hdot_oil = mdot_oil * cp_oil * (T_out-T_in)
         mdot_oil = Vdot_L_per_min * 1e-3/60 * rho_kg_per_m3
(71), B: P_loss(theta_oil) = Q(theta_oil)
(73), B: P_loss(theta_max) <= Q(theta_max)
```

如果 rho 使用 kg/L（或 kg/dm3），Vdot 使用 L/min，系数为 1/60，约 1.67e-2；如果 rho 用 kg/m3，则系数为 1.67e-5。不可混用密度单位造成 1000 倍误差。油品比热、黏度和流量必须有来源，不能靠默认数替代。

原算例只有壳体支路时，(72) 可恢复为松弛迭代：

```text
theta_new = 0.5 * [theta_old + theta_ambient + P_loss/(U*A_ca)]
```

该式不能直接用于多个并联热支路、外部冷却温度固定或强非线性损耗模型。一般情况应求 F(theta)=P_loss(theta)-Q(theta)=0，并检查根区间和残差。
